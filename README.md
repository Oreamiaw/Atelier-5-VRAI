# C
Projet de CROMBECQUE-DUBOST-FORABOSCO-THERY

Objectif du projet : rajouter au jeu de la vie un aspect jeu de rôle.
Pour cela, nous nous sommes inspirés des jeux textuels du début de l'informatique.

Nous avons une liste d'évênements sciptés. Le joueur doit alors faire les bons choix pour "établir une colonie prospère" et ainsi gagner la partie.

Nous avons choisis une grille de 60*20 afin qu'elle puisse être visualisable complètement si on augmente la taille du terminal.

Le nombre de départ d'entités sur la grille est aléatoire (compris en 60 et 120) afin de rendre les parties moins redondantes.

Aussi; chaque jour, une entité disparaît car "mangée" par le joueur. Il perd la partie si il ne lui reste plus d'entités à "manger".
